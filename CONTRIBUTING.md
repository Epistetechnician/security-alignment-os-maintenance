# Contributing

Thanks for your interest. This is a research repository with strict
claim-boundary rules, so please read `RESEARCH.md` and `AGENTS.md` first.

- Open an issue before large changes; small fixes can go straight to a pull
  request.
- Run the test commands listed in the README before submitting. Changes must not
  weaken hermetic tests or claim boundaries.
- Do not add credentials, private data, model weights, or large generated
  artifacts. Use Git LFS only where the repository already does.
- Do not raise a documented claim ceiling or relabel a negative result without a
  new, explicit protocol record and review.
- By contributing you agree your contributions are licensed under Apache-2.0.
